# r1ver cube economy candidate

Derived from the MIT-licensed [TTUN economy branch, commit b7e9a6d](https://github.com/varchaskukreja/TTUN/tree/b7e9a6db75154271185035ef856859be37dff60e). The original bot uses the official Builders TypeScript protocol wrapper. The upstream MIT copyright is retained in LICENSE.

r1ver ranks collectible cube stacks by travel distance, the number that increase stats, and whether the stack crosses a game upgrade threshold. Only currently observed cubes in one pickup radius earn a group bonus. Remembered single items retain their original distance ranking. The old bounds on diversion distance still apply. All changes to game behavior are confined to collectible selection.

The public official score for this derivative must be obtained from a new practice run. Build the root Dockerfile to run the contestant.
