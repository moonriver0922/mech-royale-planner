# S18 reached route terminals

S18 branches directly from our S09 commit `77ca91a2a3499147bbe2532dfc88bb45f937f369`. Two S09 practice replays showed a retained final waypoint inside the controller's 0.25 m horizontal stopping radius while the current cover request was farther away. In seed 45027 at tick 998 the waypoint was 0.187 m away, the requested cover was 2.970 m away, and their 2.783 m separation fell below the existing 7 m replan threshold. The position remained stationary for 20 recorded decisions before a 315 HP hit. Seed 48009 showed three analogous stationary decisions. These observations establish why S09 stopped. The effect on future damage and placement requires whole-game evaluation.

For a retained goal within the existing retarget tolerances, check whether its sole waypoint is reached and the requested destination is still outside the stop region. If the controller's normal walk check accepts the direct segment, store the request in both the waypoint and remembered destination and continue with normal movement and speed scaling. If the segment is blocked, the existing 0.6 s retry deadline and bounded lattice search apply. Adopt a detour only if its first leg also passes the current unit's walk check. A failed search holds the reached waypoint. The implementation uses the existing navigation state. It makes no change to inertia modeling, movement sampling, map geometry, combat, resource ranking or recovery thresholds.

The focused self-contained tests translate the measured tick-998 offsets onto open flat ground, advance an observation, and exercise true arrival, a clipped wall corner, an unreachable goal through multiple retry windows, and an active intermediate waypoint. Inputs for this candidate are our S09 code and its own practice traces, plus the official kit's public map, protocol and checker. Match selection and official submission are separate from implementation.
