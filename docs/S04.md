## A. Consistent laser eligibility

The independent review reproduced this state: gun reloading for 1.8 s, laser ready, a tracked opponent, reachable cube 2 m toward the safe zone. Walking without charge is safe; the charge speed cap would make departure unsafe. S02 promotes the enemy using laser readiness, then rejects charging in the executor. It moves tangentially and neither weapon fires.

Use the same eligibility rule when ranking a new laser engagement and when starting the charge. A laser that cannot start because of zone departure must not create an immediately executable combat opportunity. Gun/lightning target solving and an already-active charge retain their semantics. Compute self-only eligibility once per decision or keep it tightly bounded; avoid an extra route search per target. Keep actual urgent-zone and recovery priorities. Add a real-controller regression with the reproduced fixture. Freeze A in its own commit before B so root can assess it alone.

## B. Legal pickup alongside an existing action

Picking a weapon into an empty slot is an independent protocol action. S02 currently sends it only while the resource branch owns the decision. Assess and implement an opportunistic **laser-only** pickup from the current reported position while preserving the already-decided movement, aim, firing, reload and upgrade actions.

Require a currently visible pickup, supported laser kind, an empty slot1, no same kind in slot0, current horizontal distance at most the configured pickup radius and vertical difference at most4m, and no failed-pickup retry suppression. Do not replace weapons, predict a future position, add a detour, stop to take, or overwrite an existing valid Take action. If several qualify, use distance then ID deterministically. Picked-up weapon must be observed before its executor begins; the server equip cooldown remains authoritative. Tests must show that a legal in-range pickup can accompany a gun shot without any other action change, and reject out-of-range or filled-slot cases.

Freeze B as a second commit. Root compares A and A+B, examines actual trigger frequency and full-game points, and decides whether either merits the last official attempt. Do not integrate S03 reload changes without independent evidence of benefit.
