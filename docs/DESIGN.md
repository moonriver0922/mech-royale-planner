# S00 决策设计

每个观测周期选择一个移动目的，再在同一次决策中组装瞄准、开火、装填和拾取。目标是完成当前交战后还有能力迎接下一次交战。用比赛名次评价结果。

| 判断 | 使用的信息和动作 | 可观察的失败信号 |
| --- | --- | --- |
| 缩圈 | 从当前圈和下一圈插值。以步速、加速时间和路径长度估计到达时间。预留两个决策周期和 20% 路程。已经出圈时朝内走，在地面有余量时允许加速。朝下一圈偏内的径向点规划，地面直线受阻时用有界网格搜索 | 资源覆盖了强制进圈，或选定的绕障路线走不通、太晚到达 |
| 交战 | 用当前视线、距离、炮塔转向时间和装填估计多快能射击。差异在一个决策周期内保留既有目标，已知血量与 ID 用来平分。移动时做横移，距离较远时增加接近分量 | 换目标时反复转头，开火窗口流失，或几何可行但长期卡在原地 |
| 武器 | 机枪用匀速截击求提前量，由实际炮塔射线与预估目标位置决定开火。电弧检查当前炮塔角度、射线、距离和能量。共享瞄准方向，独立判定开火。空弹匣主动装填。安全空挡可提前装填 | 未对准时开火，常因提前装填错过完整射击，或电弧浪费能量 |
| 恢复 | 血量低于 45% 时找附近可沿地面直达并减少可见射线暴露的点。休整期间不开火，到 75% 后退出。受伤、可见射线变化或缩圈会作废选点。遮挡不足时可退向较少暴露的方向并还击 | 到点后继续受伤，等待期间恢复计时无法完成，或低血时为无效遮挡持续绕路 |
| 资源 | 缩圈和恢复优先。短时间可兑现的交战优先于资源。资源按地面可达性和取得时间比较，只有有增益的方块与空槽电弧枪能直接成为目标。有空档且有用时才打箱，估计额外射击和装填时间。按当前水平和垂直範围发送拾取。升级按配置中的效果与实际装备比较相对增益 | 从未使用捡到的装备，频繁拾取失败，绕路消耗多于资源价值 |
| 探索 | 无目标时朝圈内不同方向地面探索，以最近的可见威胁或近响声调整朝向 | 反复回到同一处、错过早期可用资源，或被几何卡住 |

对手弹药、冷却、意图和未来路线不可见。几何检查处理实体地形、桥洞和净空，采用有界地面导航。动态实体和植被遮挡不进入路径预估，楼顶跨层、激光、迫击炮和复杂弹道规避留到后续。路径为预计路线，控制器用当前姿态和当前位置校验动作。恢复与资源的数值是首版决定，首评前未做参数搜索。

首个 Practice 结果用于建立独立线基线。S01 可固定当前目标，把横移、接近和退路放进同一段短时评价，先验证实际动作改变，再比较官方结果。
