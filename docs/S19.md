# S19 held-motion check for passive navigation

Three recorded S09 actions cleared the ordinary forward lookahead, then arrived inside the model's blocked body footprint one decision later. S09's own horizontal acceleration integration reproduced all three next centers. S19 checks whether incoming velocity will carry a walking mech into a static obstacle before the next command can take effect.

S19 descends directly from S09 commit `77ca91a2a3499147bbe2532dfc88bb45f937f369`. The change applies after recovery, ordinary resource follow, or scouting assembles the action. Urgent zone movement and both active combat branches keep their own actions. The check requires ground contact within 0.1 m of modeled terrain, in-zone status, a valid starting body footprint and a nonzero movement vector. Boost, jump, either fire trigger, pickup, upgrade selection, and any observed, held or pending laser charge bypass it. An equipped neutral laser is eligible. Reload alone is eligible.

For a held decision of N physics ticks, start with observed feet and horizontal velocity. Each tick advances S09's walkTick using effective walk speed, ground acceleration, the actual movement magnitude and the configured tick duration. Check each consecutive center-to-center Segment with the original full body and terrain rules. Return the original input verbatim if all N segments clear. Only a projected collision starts the finite alternative search.

Try the existing turn offsets around the **emitted** heading in stable order (+0.5, −0.5, +1.1, −1.1, +1.7, −1.7, π radians). Each turn needs the standard full three-decision forward lookahead and projected zone check, and every held substep must clear the geometry and remain in the predicted circle. Each nonzero replacement retains the original magnitude. Last, try zero input with the same velocity, deceleration and per-tick zone/geometry checks. Preserve the original command if that brake also fails. Only the Move field is replaceable. Existing movement-state bookkeeping consumes the final issued Move.

The incremental search costs at most one starting-footprint query, seven forward queries and nine held integrations of at most N ticks apiece. At the official two-tick cadence this bounds additional Segment queries at 26 per eligible decision. The ordinary clear path uses three. No candidate requests a route search.

## Replaying the witnesses

Run the Go tests with `S19_RECORDINGS` set to the directory containing the three original S09 observation/action JSONL files listed in the regression test. Set `S19_ARENA` to the official kit's arena directory if the recording's hello map location needs relocation. The test reconstructs controller history, requires exact action equality through the preceding observation, checks the original prediction against the recorded next center and verifies a nonzero, equal-magnitude, fully clear replacement with identical remaining action fields.

The recorded divergences occur at seed 48009 tick 1516 (uncovered retreat), 45027 tick 1132 (walking to cover with an uncharged laser) and 49018 tick 948 (scouting). All three first fail the **second** held physics substep. The earlier diagnostic search enumerated angles around the requested waypoint or escape bearing. S19 uses the final emitted heading, so a valid alternative can differ from that probe.

The local recording engine allows overlaps that the controller geometry rejects. A terrain-projected feet height can also differ from the observed bridge height. These fixtures demonstrate prevention of three predicted horizontal entries over one command. They cannot establish official collision semantics, future damage or match placement. Seed 45015 begins inside an expanded footprint, beyond the reach of any previous-action correction.
